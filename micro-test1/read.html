Читать перед тестом

Только чтение, ничего решать не надо. Девять правил, которые закрывают все 20 типов задач. Примерно 15 минут.

На тесте

  • Одна задача из части A, одна из части B, 35 минут.
  • Начинай с (a): там обычно механика.
  • Пиши условие оптимума до чисел: за постановку дают баллы.
  • Рисуй график: оси q и p, подписи кривых, оптимум с пунктиром на обе оси.
A.1, A.2

Монополия и предложение

Монополия: MR = MC, цену снимаешь с кривой спроса.

  • Линейный спрос p = a − bq даёт MR = a − 2bq: та же точка на оси p, наклон вдвое круче.
  • Предложение price-taker: p = MC, но только выше порога. Порог — минимум AC, если C(0) = 0, или минимум AVC, если фиксированные издержки утоплены. Ниже порога выпуск 0.
  • Спрос вида A/p²: эластичность −2, значит p = 2·MC.
  • DWL: эффективный объём там, где спрос пересекает MC.

PS = прибыль + фиксированные издержки.

A.3, A.5, A.8

Два потребителя

Спросы складываешь по количеству при одной цене. Получается излом.

  • Выше меньшего пересечения с осью p покупает только сильный, ниже — оба.
  • Единая цена: реши MR = MC на каждом куске и сравни прибыли. Иногда выгоднее не обслуживать слабого.
  • 1-я степень: цена за единицу = MC, взнос F = CS каждого. Прибыль = весь излишек, DWL = 0.
  • 3-я степень: MRᵢ = MC на каждом рынке. MR рынков равны между собой при любых издержках.

обратные спросы не складывают.

A.4

Двухчастный тариф F + pq

  • Только сильному: p = MC, F = весь его CS.
  • Обоим: F = CS слабого. Цена из (p − c)·|D′| = D₁ − D₂.
  • Сравни две прибыли. Обоих выгодно обслуживать, когда спросы похожи.
A.6, A.7

Монополист и мировой рынок

MC(Q) = pw = MR(qd). Экспорт = Q − qd.

  • Всё продаёт дома, пока pw ≤ уровня, где MR = MC без мирового рынка.
  • Всё уходит на экспорт, когда pw ≥ MR(0), то есть верхней точки спроса.
  • Доля s за рубежом: подставь qd = (1 − s)Q в MR = MC.

домашняя цена выше мировой, равны только MR и pw.

A.9, A.10

Монопсония

MV = MBC, платит цену с кривой предложения.

  • Предложение p = a + bq даёт MBC = a + 2bq.
  • Эффективно: MV = кривая предложения.
  • С мировым рынком: MV(Q) = pw, MBC(qd) = pw. Всё дома при pw ≥ MBC в обычном оптимуме, всё импорт при pw ≤ MBC(0).
B.1, B.2, B.3

Штучный спрос: таблица

  • Отсортируй готовность платить по убыванию.
  • Эффективно: продаёшь, пока ω ≥ MC. Если MC падает, считай Σω − C(k) для всех k.
  • Единая цена: продать k штук по цене ωk, прибыль k·ωk − C(k). Проверь каждую группу.
  • 1-я и 3-я степень: каждому его ω, объём эффективный.
  • Работники (B.3): зарплата ck всем, прибыль R(k) − k·ck.

кусочные издержки: C(40) в B.1 равно 260, а не 6·40.

B.4, B.5

Бандлинг

  • Для каждого товара два кандидата цены: низкая (покупают все) и высокая (только тот, кто ценит больше).
  • Набор: ценность = сумма ценностей, те же два кандидата.
  • Найди x, где кандидаты равны, разбей ось и сравни на каждом куске.

строго больше: концы интервала обычно не входят.

B.6, B.7

Две версии товара

Слабый платит всю свою ценность дешёвой версии. Сильный безразличен между версиями.

  • pL = ценность L у слабого.
  • pH = ценность H у сильного − (ценность L у сильного − pL).
  • Сравни с вариантом «только дорогая версия»: max(всем по низкой, только сильному по высокой).

вычитай MC версии из цены каждой проданной штуки.

B.8, B.9, B.10

Выбор качества

Сверху без искажений, снизу качество занижено.

  • vH = aq, vL = bq, c = q², a > b.
  • Цены по покупателю: q = a/2 и b/2, каждый платит всю ценность.
  • Без дискриминации: pL = b·qL, pH = a·qH − (a − b)·qL.
  • qH = a/2. Для двух покупателей qL = b − a/2. Для долей x и 1 − x: qL = ½·[b − x(a − b)/(1 − x)].
  • Если qL ≤ 0, слабому ничего не продают.

сначала определи, кто сильный: в B.9 это зависит от α.

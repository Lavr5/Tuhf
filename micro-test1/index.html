Формулы-минимум

Тест closed-book, поэтому это нужно знать наизусть

Линейный спрос

\(p=a-bq\;\Rightarrow\; D(p)=\frac{a-p}{b}\), \(MR=a-2bq\)

\(CS=\tfrac12(a-p)\,q\)

Монополия

\(MR=p(q)+p'(q)\,q=MC\), затем \(p^m=p(q^m)\)

Лернер: \(\frac{p-MC}{p}=-\frac1\varepsilon\), \(\varepsilon=\frac{p\,D'(p)}{D(p)}\)

Излишки

\(CS=\int_0^q p(x)\,dx-pq\)

\(PS=pq-VC(q)\), прибыль \(=PS-F\)

\(DWL=SW^*-SW\), где \(q^*\): \(p(q^*)=MC(q^*)\)

Предложение фирмы

\(p=MC(q)\) выше порога \(p_s=\min AC\) (если \(C(0)=0\)) или \(\min AVC\) (если \(C(0)=F\))

Монопсония

\(MBC=p(q)+p'(q)\,q\), \(MV=V'(q)\)

\(MV=MBC\), цена \(p^m=p(q^m)\) по кривой предложения

Дискриминация

1-я: цена \(=MC\), взнос \(F_i=CS_i\)

3-я: \(MR_i(q_i)=MC(Q)\) для каждого рынка

Тариф на обоих: \(F=CS_2(p)\), \((p-c)\,|D'(p)|=D_1(p)-D_2(p)\)

Мировой рынок

\(MC(Q)=p_w=MR(q_d)\), \(q_w=Q-q_d\)

Всё дома: \(p_w\le MR(q^m)\). Всё за рубеж: \(p_w\ge MR(0)\)

Штучный спрос

Единая цена: прибыль \(k\,\omega_k-C(k)\)

1-я степень: \(\sum_{i\le k}\omega_i-C(k)\), \(q^m=q^*\)

Две версии / качество

Низкий тип платит всю свою ценность: \(p_L=v_L(q_L)\)

Высокий: \(p_H=v_H(q_H)-\big[v_H(q_L)-v_L(q_L)\big]\)

\(q_H\) эффективно, \(q_L\) занижено

A·1

Монополия и предложение фирмы

Задачи банка A.1, A.2 · лекция 1a, семинар 2

Как узнать

Один продавец, даны спрос \(D(p)\) и издержки \(C(q)\). Просят функцию предложения price-taker, монопольный исход \((q^m,p^m)\), CS, PS, DWL.

Рецепт

Функция предложения (price-taker)

  1. Раздели издержки: \(C(q)=F+VC(q)\), \(MC=C'(q)\). Если \(C(0)=0\), фиксированные издержки избегаемые, порог считаем по \(\min AC\). Если \(C(0)=F\), они утоплены, порог по \(\min AVC\).
  2. Порог закрытия: реши \(MC(q_s)=AC(q_s)\) (или \(=AVC\)), цена \(p_s=MC(q_s)\).
  3. Выше порога фирма идёт по MC: \(p=MC(q)\Rightarrow q=MC^{-1}(p)\).
  4. Ответ кусочно: \(s(p)=0\) при \(p\lt p_s\); \(\{0;\,q_s\}\) при \(p=p_s\); \(MC^{-1}(p)\) при \(p\gt p_s\).

Монополия

  1. Обратный спрос \(p(q)\), \(MR=p(q)+p'(q)\,q\). Для \(p=a-bq\): \(MR=a-2bq\).
  2. \(MR(q^m)=MC(q^m)\), затем \(p^m=p(q^m)\).
  3. Проверки: \(MR'-MC'\lt 0\) (SOC) и \(\pi(q^m)\ge\pi(0)\) (при \(C(0)=0\) это \(\pi\ge0\)).
  4. \(CS=\int_0^{q}p(x)dx-pq\), \(PS=pq-VC\), прибыль \(=PS-F\). Для DWL найди \(q^*\) из \(p(q)=MC(q)\).

Спрос вида \(D=A\,p^{-k}\): эластичность постоянна, \(\varepsilon=-k\), и сразу \(p^m=\frac{k}{k-1}\,MC\).

PS и прибыль различаются на фиксированные издержки: PS = π + F.

Банк A.1Supply Curve and Monopoly Outcome

\(D(p)=8-\frac p2\); \(C(q)=0\) при \(q=0\), \(C(q)=\frac43+\frac{2q^3}{3}\) при \(q\gt0\). (a) Предложение price-taker. (b) Монопольный исход. (c) CS, PS и прибыль монополии.

  1. (a) Предложение

    \(MC=2q^2\), \(AC=\frac{4}{3q}+\frac{2q^2}{3}\). \(C(0)=0\), значит \(F=\frac43\) избегаемые и порог по \(\min AC\): \(2q^2=\frac{4}{3q}+\frac{2q^2}{3}\Rightarrow \frac43q^2=\frac4{3q}\Rightarrow q_s=1\), \(p_s=MC(1)=2\).

    Выше порога \(p=2q^2\Rightarrow q=\sqrt{p/2}\).

    \(s(p)=0\) при \(p\lt2\); \(\{0;1\}\) при \(p=2\); \(\sqrt{p/2}\) при \(p\gt2\).

  2. (b) Монополия

    \(p(q)=16-2q\), \(MR=16-4q\). \(16-4q=2q^2\Rightarrow q^2+2q-8=0\Rightarrow q=2\) (корень \(-4\) отбрасываем).

    SOC: \(MR'=-4\lt MC'=4q=8\). Прибыль \(24-\left(\frac43+\frac{16}3\right)=\frac{52}3\gt0\), закрываться невыгодно.

    \(q^m=2\), \(p^m=12\).

  3. (c) Излишки

    \(CS=\tfrac12(16-12)\cdot2=4\). \(PS=pq-VC=24-\frac{2\cdot8}{3}=\frac{56}3\approx18{,}67\). Прибыль \(=PS-F=\frac{56}3-\frac43=\frac{52}3\approx17{,}33\).

    CS = 4, PS = 56/3, π = 52/3.

Банк A.2Monopoly Outcome and Deadweight Loss

\(D(p)=\frac4{p^2}\), \(C(q)=\frac q4\). (a) Монопольный исход. (b) CS, PS, SW. (c) DWL.

  1. (a) Монополия

    \(\varepsilon=\frac{p\,D'(p)}{D}=\frac{p\cdot(-8/p^3)}{4/p^2}=-2\). Лернер: \(\frac{p-MC}{p}=\frac12\Rightarrow p=2MC=\frac12\). Тот же ответ через MR: \(p(q)=\frac2{\sqrt q}\), \(MR=\frac1{\sqrt q}=\frac14\Rightarrow q=16\).

    \(q^m=16\), \(p^m=\frac12\).

  2. (b) Излишки

    \(CS=\int_0^{16}\frac{2}{\sqrt x}dx-\frac12\cdot16=4\sqrt{16}-8=8\). \(PS=8-\frac{16}4=4\).

    CS = 8, PS = 4, SW = 12.

  3. (c) DWL

    Эффективно: \(p=MC=\frac14\Rightarrow q^*=\frac{4}{1/16}=64\). \(DWL=\int_{16}^{64}\left(\frac2{\sqrt x}-\frac14\right)dx=\big[4\sqrt x\big]_{16}^{64}-\frac{48}4=16-12\).

    DWL = 4.

A·2

Несколько потребителей

Задачи банка A.3, A.5, A.8 и пункт (a) задачи A.4 · лекция 1b, семинар 4

Как узнать

Даны два обратных спроса \(p_1(q)\), \(p_2(q)\). Просят рыночный спрос, монополию с единой ценой (linear pricing), 1-ю или 3-ю степень дискриминации.

Рецепт

(a) Рыночный спрос

  1. Переверни каждый: \(p_i=a_i-b_iq\Rightarrow D_i(p)=\frac{a_i-p}{b_i}\) при \(p\lt a_i\), иначе 0.
  2. Складывай по количеству при одной цене, по диапазонам: \(D=D_1\) при \(a_2\le p\lt a_1\); \(D=D_1+D_2\) при \(p\lt a_2\).
  3. Точка излома \(q_k=D_1(a_2)\). Обратный: \(p(q)=p_1(q)\) при \(q\le q_k\); при \(q\gt q_k\) обращаешь \(D_1+D_2\).

(b) Единая цена при изломе

  1. На каждом куске реши \(MR=MC\). Проверь, что \(q\) лежит в своём куске; если нет, кандидат на этом куске — точка излома.
  2. Посчитай прибыль каждого кандидата и выбери большую. Индивидуальные объёмы \(q_i=D_i(p^m)\).

1-я степень

  1. Цена за единицу равна MC: при \(C=cq\) получаем \(q_i^*=D_i(c)\).
  2. Личный двухчастный тариф \(T_i(q)=F_i+c\,q\), \(F_i=CS_i(c)=\tfrac12(a_i-c)\,q_i^*\). Прибыль \(=\sum F_i=SW^*\), DWL = 0.

3-я степень

  1. \(MR_i(q_i)=MC(Q)\) на каждом обслуживаемом рынке. При \(C=cq\): \(q_i=\frac{a_i-c}{2b_i}\), если \(a_i\gt c\).
  2. \(p_i=p_i(q_i)\), прибыль \(\sum(p_i-c)\,q_i\). Даже без знания \(C\) верно \(MR_1(q_1)=MR_2(q_2)\), и это решает A.8.

обратные спросы НЕ складывают: p₁ + p₂ ничего не значит.

в (b) обязательно сравни прибыль на обоих кусках, иногда выгоднее не обслуживать второго.

Банк A.3Monopoly Problem with 1st-degree PD

\(p_1=12-q\), \(p_2=8-q\), \(C=2q\). (a) Рыночный и обратный рыночный спрос. (b) Единая цена: исход и прибыль. (c) 1-я степень: исход и прибыль.

  1. (a) Рыночный спрос

    \(D_1=12-p\) (\(p\le12\)), \(D_2=8-p\) (\(p\le8\)).

    \[D(p)=\begin{cases}0, & p\ge12\\ 12-p, & 8\le p\lt12\\ 20-2p, & 0\le p\lt8\end{cases}\qquad p(q)=\begin{cases}12-q, & 0\le q\le4\\ 10-\frac q2, & 4\lt q\le20\end{cases}\]

    Излом в \(q=D(8)=4\).

  2. (b) Единая цена

    Кусок \(q\gt4\): \(MR=10-q=2\Rightarrow q=8\), лежит в куске; \(p=6\), \(\pi=4\cdot8=32\).

    Кусок \(q\le4\): \(MR=12-2q=2\Rightarrow q=5\notin[0;4]\), лучший кандидат — излом: \(q=4\), \(p=8\), \(\pi=24\).

    \(p^m=6\), \(Q=8\) (\(q_1=6\), \(q_2=2\)), \(\pi=32\).

  3. (c) 1-я степень

    Цена за единицу \(=MC=2\): \(q_1=10\), \(q_2=6\). Взносы \(F_1=\tfrac12\cdot10\cdot10=50\), \(F_2=\tfrac12\cdot6\cdot6=18\). Тарифы \(T_1=50+2q\), \(T_2=18+2q\).

    \(Q=16\), \(\pi=68=SW^*\), CS = 0, DWL = 0.

\(p_1=8-q\), \(p_2=4-q\), \(C=2q\). (a) Рыночный спрос. (b) Единая цена. (c) 3-я степень.

Банк A.8Third-degree Price Discrimination

\(D_1=10-p\), \(D_2=15-p\), 3-я степень, \(C\) неизвестна (\(C'\ge0\), \(C''\ge0\)), продаёт на обоих рынках. (a) \(q_2^m-q_1^m\). (b) \(p_2^m-p_1^m\). (c) Максимально возможный выпуск без субсидий.

  1. (a) Разница объёмов

    \(MR_1=10-2q_1\), \(MR_2=15-2q_2\). В оптимуме оба равны \(MC(Q)\), значит равны друг другу: \(10-2q_1=15-2q_2\).

    \(q_2-q_1=2{,}5\) при любой функции издержек.

  2. (b) Разница цен

    \(p_2-p_1=(15-q_2)-(10-q_1)=5-(q_2-q_1)\).

    \(p_2-p_1=2{,}5\).

  3. (c) Максимальный выпуск

    Без субсидии \(MC\ge0\), значит \(MR_i=MC\ge0\): \(q_1\le5\), \(q_2\le7{,}5\). Граница достигается при \(MC=0\) (например, \(C(q)=0\)).

    \(Q_{\max}=12{,}5\).

Монополист и мировой рынок

Задачи банка A.6, A.7 · семинар 3 Q3

Как узнать

Дома монополист с единой ценой, за рубежом можно продать сколько угодно по цене \(p_w\). Мировая цена играет роль постоянного предельного дохода от экспорта.

Рецепт
  1. Если экспорт положителен: весь выпуск \(Q\) из \(MC(Q)=p_w\); домашний объём \(q_d\) из \(MR(q_d)=p_w\); экспорт \(q_w=Q-q_d\); домашняя цена \(p_d=p(q_d)\).

  5. Доля \(s\) за рубежом: \(q_d=(1-s)Q\), реши \(MR\big((1-s)Q\big)=MC(Q)\), затем \(p_w=MC(Q)\).

домашняя цена выше мировой: p_d > p_w, равны только MR и p_w.

Как узнать

Один покупатель с ценностью \(V(q)\) и конкурентные поставщики. Это зеркало монополии: вместо MR и MC здесь MV и MBC.

Рецепт
  1. Предложение поставщика: \(p=MC_i(q)\Rightarrow s_i(p)\). Рыночное \(S=\sum s_i\), обратное \(p(q)\).

B·2

Бандлинг

Задачи банка B.4, B.5 · лекция 1c, семинар 4 Q2

Как узнать

Два товара A и B, каждому покупателю нужно не больше одной штуки каждого. Сравнивают продажу по отдельности и продажу набором (pure bundling) в зависимости от параметра.

Рецепт
  1. Раздельно: для каждого товара два кандидата цены: низкая (покупают все) и высокая (покупает только тот, кто ценит больше). Прибыль товара \(=\max\). С издержками считай \((p-c)\cdot\) число покупателей.
  2. С параметром найди, где два кандидата равны: это точка переключения. Запиши прибыль кусочно.
  3. Набором: ценность набора у каждого \(=\omega_A+\omega_B\), издержки \(c_A+c_B\), те же два кандидата.
  4. Разбей ось параметра всеми точками переключения и сравни на каждом интервале. Следи за строгостью неравенства на концах.

если параметр сидит в ценности (B.4), порядок покупателей меняется, когда x переходит через чужую ценность. Это тоже точка разбиения.

Потребитель 1: A = 1, B = 4. Потребитель 2: A = 3, B = x, \(x\in(0;8)\). Издержек нет. (a) Прибыль при раздельной продаже. (b) Прибыль набором. (c) При каких x набор строго лучше.

  1. (a) Раздельно

    A: цена 1 даёт 2, цена 3 даёт 3, итого \(\pi_A=3\).

    B при \(x\lt4\): цена \(x\) даёт \(2x\), цена 4 даёт 4, то есть 4 при \(x\le2\) и \(2x\) при \(2\le x\le4\). При \(x\ge4\): цена 4 даёт 8, цена \(x\) даёт \(x\lt8\), итого 8.

    \[\pi_S=\begin{cases}7, & 0\lt x\le2\\ 3+2x, & 2\le x\le4\\ 11, & 4\le x\lt8\end{cases}\]
  2. (b) Набором

    Ценности набора: 5 и \(3+x\). При \(x\lt2\): цена \(3+x\) даёт \(6+2x\) (больше 5). При \(x\ge2\): цена 5 даёт 10, цена \(3+x\) даёт \(3+x\).

    \[\pi_B=\begin{cases}6+2x, & 0\lt x\le2\\ 10, & 2\le x\le7\\ 3+x, & 7\le x\lt8\end{cases}\]
  3. (c) Сравнение

    \((0;2]\): \(6+2x\gt7\iff x\gt0{,}5\). \([2;4]\): \(10\gt3+2x\iff x\lt3{,}5\). \([4;7]\): \(10\lt11\). \([7;8)\): \(3+x\lt11\).

    Набор строго лучше при \(x\in(0{,}5;\,3{,}5)\).

Банк B.5Bundling Problem II

100 покупателей: x типа I (A = 3, B = 11), 100 − x типа II (A = 5, B = 7). \(c_A=c_B=1\). (a) Раздельно. (b) Набором. (c) При каких x раздельная продажа строго лучше.

  1. (a) Раздельно

    A: цена 3 даёт \(2\cdot100=200\); цена 5 даёт \(4(100-x)\), это больше 200 при \(x\le50\).

    B: цена 7 даёт \(6\cdot100=600\); цена 11 даёт \(10x\), это больше 600 при \(x\ge60\).

    \[\pi_S=\begin{cases}1000-4x, & 0\le x\le50\\ 800, & 50\le x\le60\\ 200+10x, & 60\le x\le100\end{cases}\]
  2. (b) Набором

    Ценности: I = 14, II = 12, издержки 2. Цена 12 даёт \(10\cdot100=1000\); цена 14 даёт \(12x\), это больше при \(x\ge\frac{250}3\approx83{,}3\).

    \[\pi_B=\begin{cases}1000, & x\le 83{,}3\\ 12x, & x\ge83{,}3\end{cases}\]
  3. (c) Сравнение

    Раздельно строго лучше при \(x\in(80;\,100)\), то есть x = 81, …, 99.

B·3

Две версии товара

Задачи банка B.6, B.7 · лекция 1c, семинар 4 Q3

Как узнать

Товар в двух готовых версиях (Fancy / Basic, Top / Xlam), два типа покупателей со штучным спросом. Цену по покупателю назначать нельзя, только по версии.

Рецепт
  1. Только дорогая версия H: как штучный спрос: низкая цена (покупают все) или высокая (только сильный тип). Прибыль \(=\max\).
  2. H сильному, L слабому: слабый платит всю свою ценность L: \(p_L=\omega_L^{\text{слаб}}\).
  3. Сильный безразличен между H и L: \(\omega_H^{\text{сил}}-p_H=\omega_L^{\text{сил}}-p_L\Rightarrow p_H=\omega_H^{\text{сил}}-(\omega_L^{\text{сил}}-p_L)\).
  4. Проверь, что слабый не хочет H: \(\omega_L^{\text{слаб}}-p_L\ge\omega_H^{\text{слаб}}-p_H\). Прибыль \(=\) доли \(\times(p-c)\).
  5. Сравни варианты и найди интервал параметра.

Продавать только L невыгодно: при тех же покупателях H приносит больше.

если у версии есть предельные издержки (Top в B.7), вычитай их из цены каждой проданной штуки.

Банк B.6Vertical Differentiation Problem I

Доля x типа I (Fancy 13, Basic 8), доля 1 − x типа II (Fancy 6, Basic 4). Издержки 0. (a) Только Fancy. (b) Fancy типу I, Basic типу II. (c) При каких x выгоднее предлагать обе версии.

  1. (a) Только Fancy

    Цена 6 (покупают все) даёт 6; цена 13 (только тип I) даёт \(13x\).

    \(\pi_F=6\) при \(x\le\frac6{13}\); \(13x\) при \(x\ge\frac6{13}\).

  2. (b) Обе версии

    \(p_B=4\). Тип I безразличен: \(13-p_F=8-4\Rightarrow p_F=9\). Проверка типа II: \(4-4=0\ge6-9=-3\).

    \(\pi=9x+4(1-x)=4+5x\).

  3. (c) Когда обе лучше

    \(4+5x\gt6\iff x\gt0{,}4\) и \(4+5x\gt13x\iff x\lt0{,}5\).

    \(x\in(0{,}4;\,0{,}5)\).

Банк B.7Vertical Differentiation Problem II

Потребитель 1: Top \(8+y\), Xlam 5,5. Потребитель 2: Top 5, Xlam 3. MC Top = 1, MC Xlam = 0, \(y\ge0\). (a) Только Top. (b) Top одному, Xlam другому. (c) При каких y лучше только Top.

  1. (a) Только Top

    Цена 5 даёт \(2\cdot(5-1)=8\); цена \(8+y\) даёт \(7+y\).

    \(\pi_T=8\) при \(y\le1\); \(7+y\) при \(y\ge1\).

  2. (b) Top первому, Xlam второму

    \(p_X=3\). Первый безразличен: \(8+y-p_T=5{,}5-3\Rightarrow p_T=5{,}5+y\). Второй: \(0\ge5-5{,}5-y\), выполнено.

    Наоборот (Top второму) нельзя: нужно одновременно \(p_T-p_X\le2\) и \(p_T-p_X\ge2{,}5+y\).

    \(\pi=(5{,}5+y-1)+3=7{,}5+y\).

  3. (c) Когда только Top

    \(y\le1\): \(8\gt7{,}5+y\iff y\lt0{,}5\). \(y\ge1\): \(7+y\lt7{,}5+y\) всегда.

    \(y\in[0;\,0{,}5)\).

B·4

Выбор качества

Задачи банка B.8, B.9, B.10 · лекция 1c (iPhone для внука и бабушки)

Как узнать

Фирма сама выбирает качество \(q\) (мощность, площадь). Ценности линейные \(v_H=a\,q\), \(v_L=b\,q\) с \(a\gt b\), издержки \(c(q)=q^2\) за каждую штуку.

Рецепт
  1. Определи сильный тип: у кого коэффициент больше. В B.9 это зависит от \(\alpha\), проверь по диапазону.
  2. (a) Цены по покупателю: каждому эффективное качество: \(\max\,aq-q^2\Rightarrow q_H=\frac a2\), \(p_H=a\,q_H\), прибыль \(\frac{a^2}4\). Так же \(q_L=\frac b2\), прибыль \(\frac{b^2}4\).
  3. (b) Без дискриминации: \(p_L=b\,q_L\), \(p_H=a\,q_H-(a-b)\,q_L\). Последнее слагаемое — информационная рента сильного типа.
  4. Подставь цены в прибыль: \(x\,[a q_H-(a-b)q_L-q_H^2]+(1-x)\,[b q_L-q_L^2]\). Отсюда \(q_H=\frac a2\) (сверху без искажений) и \(q_L=\frac12\big[b-\frac{x}{1-x}(a-b)\big]\). Для двух покупателей (\(x=\frac12\)): \(q_L=b-\frac a2\).
  5. Две разные машины с положительным качеством ⇔ \(q_L\gt0\). Иначе угловое решение: \(q_L=0\), продаётся только H по \(p_H=a\,q_H\).
  6. (c) Подставь числа: \(q\), \(p\), прибыль \(\sum(p-c)\), \(SW=\sum(v-c)\), \(SW^*\) из (a), \(DWL=SW^*-SW\). \(CS_H=(a-b)\,q_L\), \(CS_L=0\).

цена качественной версии не равна a·q_H: из неё вычитается рента (a − b)·q_L.

если издержки другие, например q²/2, формулы q_H и q_L меняются. Выводи условие первого порядка каждый раз.

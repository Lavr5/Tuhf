# Tuhf

- [`matstat-exam/index.html`](matstat-exam/index.html) — конспект для подготовки к экзамену по математической статистике (оценки, Рао–Крамер, достаточные статистики, доверительные интервалы, критерии, регрессия, разобранные задачи, таблицы квантилей). Формулы рендерит MathJax.
- [`matstat-practice/index.html`](matstat-practice/index.html) — тренажёр по точечным оценкам: все задачи семинаров 1–8 и ДЗ №5 с пошаговыми разборами, задачами для самопроверки и шпаргалкой «увидел в условии → делаю».
- [`matstat-practice/dz6.html`](matstat-practice/dz6.html) — решение ДЗ №6 (ММ/ММП, достаточность, Рао–Крамер, теоретические частоты, доверительные интервалы).
- [`matstat-practice/ikr1.html`](matstat-practice/ikr1.html) — подготовка к ИКР1: все 26 задач из листа «Возможные варианты задач ДКР1, АКР1 и экзамена» (ММ/ММП, несмещённость, состоятельность, Рао–Крамер, теоретические частоты, критерий Пирсона, доверительные интервалы) с решениями и сводкой формул.
- [`matstat-practice/dkr1.html`](matstat-practice/dkr1.html) — решение ДКР №1 по разделу «Статистическое оценивание»: ММП и Рао–Крамер, равномерный закон, геометрическое распределение (ряд, полигон, кумулята, теоретические частоты), характеристики интервального ряда, доверительные интервалы для среднего, СКО и доли.

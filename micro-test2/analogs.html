A.8Скидываемся на ремонт

Ремонт стоит 3. Ценности: Том 2, Джерри 1, Спайк 1. s ∈ {0, 1, 2, 3}, платёж 3si/S при S ≥ 3. При безразличии предпочитают ремонт.

  1. Без ремонта: игрок i может добавить 3 − S−i и заплатить столько же; не захочет, только если 3 − S−i > vi. Условия: sJ + sS = 0, sT + sS ≤ 1, sT + sJ ≤ 1.
  2. С ремонтом: при S > 3 кто-то снизит взнос, значит S = 3 и каждый платит si; нужно si ≤ vi.
  3. По очереди. Спайк: если сумма двоих 2, добавляет 1; если ≥ 3, даёт 0; иначе ремонта нет.
  4. Джерри: при s1 = 1 даёт 1 (платит 1, выигрыш 0, предпочитает ремонт); при s1 = 2 даёт 0. Том: s1 = 1 даёт ему 1, s1 = 2 даёт 0.

Без ремонта: (0, 0, 0), (1, 0, 0). С ремонтом: (2, 1, 0), (2, 0, 1), (1, 1, 1). По очереди: (1, 1, 1), выигрыши 1, 0, 0.

A.4 · Traffic Game I

Пробки

Из города A в город B ведут три дороги. На верхней и нижней бывают пробки: чем больше машин, тем дольше ехать. Средняя дорога всегда занимает одно и то же время.

Главная мысль. Водители сами разбегаются по дорогам так, что на всех дорогах, где кто-то едет, время одинаковое.

Инструкция

  1. Найди дорогу без пробок. Её время станет общим временем для всех.
  2. Для каждой дороги с пробками скажи: «время на ней равно общему». Отсюда получишь, сколько на ней машин.
  3. Остальные машины едут по дороге без пробок.
  4. Если на дорогу без пробок машин не осталось или получилось меньше нуля, её никто не выбирает. Тогда дели машины между двумя пробочными: время на них одинаковое, а машин в сумме сколько дано.

Пример из банка

Верх: 10 + z/10. Середина: 40. Низ: 20 + z/10. Едут 1000 машин.

Общее время 40. Верх: 10 + z/10 = 40, значит 300 машин. Низ: 20 + z/10 = 40, значит 200. По середине оставшиеся 500.

В обратную сторону середина закрыта (она односторонняя). Тогда только верх и низ: 550 и 450, по 65 минут.

Запомни: дорога без пробок задаёт время для всех.

A.5 · Traffic Game II

Платная дорога

Та же картина, но средняя дорога платная. Водители считают, что 10 рублей — это одна минута.

Главная мысль. Переведи плату в минуты и прибавь ко времени. Дальше это задача A.4.

Инструкция

  1. Плата X рублей — это X/10 минут. Время средней дороги: 30 + X/10.
  2. Реши, как в A.4: это время общее для всех дорог.
  3. Выручка = плата × число машин на средней дороге.
  4. Чтобы найти лучшую плату: запиши число машин на средней через X, умножь на X и найди вершину параболы.

Пример из банка

При X = 100 средняя дорога стоит 40 минут. Сверху 250, снизу 150, по середине 600. Выручка 60 000.

По середине едет 800 − 2X машин. Выручка X · (800 − 2X) больше всего при X = 200: это 80 000.

Запомни: рубли переводим в минуты, и задача сводится к A.4.

A.6 · Partnership Game

Партнёры

Том и Джерри вместе владеют сыроварней, каждому половина прибыли. Каждый сам решает, сколько часов работать. Работать тяжело: у каждого свои издержки.

Главная мысль. Каждый выбирает свои часы, глядя на часы другого. Это «лучший ответ». Равновесие — там, где лучшие ответы встречаются.

Инструкция

  1. Выигрыш игрока = половина прибыли фирмы минус его издержки.
  2. Возьми производную по своим часам и приравняй к нулю. Получишь «мои часы = формула от часов другого». Это лучший ответ.
  3. Посмотри, какие значения лучший ответ вообще может принять. Всё, что вне этого диапазона, игрок никогда не выберет. Это строго доминируемые стратегии.
  4. Реши систему из двух лучших ответов. Это равновесие Нэша.

Пример из банка

Лучший ответ Тома: его часы = 1 + часы Джерри. Лучший ответ Джерри: его часы = (1 + часы Тома) / 2.

Подставляем одно в другое: Джерри работает 2 часа, Том 3 часа.

Запомни: производная по своей переменной равна нулю, это и есть лучший ответ.

A.7 · Matrix Game played Sequentially

Игра по очереди

Первый игрок выбирает x, y или z. Если он выбрал z, игра заканчивается. Если x или y, второй игрок это видит и выбирает A или B.

Главная мысль. Решаем с конца. Сначала думаем, что сделает второй, потом первый.

Инструкция

  1. Нарисуй дерево. Сверху первый игрок, от него три ветки. На ветках x и y стоит второй игрок, от него по две ветки. Внизу выигрыши.
  2. Стратегия второго — это план на оба случая. Например, «AB» значит: после x играю A, после y играю B. Всего четыре плана: AA, AB, BA, BB.
  3. Для равновесий Нэша составь таблицу 3 × 4 и подчеркни лучшие ответы обоих.
  4. Для SPNE иди с конца: в каждом узле второй берёт то, что ему лучше. Потом первый смотрит, что получит от каждой ветки, и выбирает лучшее.

Пример из банка

После x второму лучше A (10 больше 0). После y лучше B (10 больше 0). Его план: AB.

Тогда первый получает: за x — 8, за y — 6, за z — 8. Подходят x и z.

Ответ SPNE: (x, AB) и (z, AB).

Запомни: SPNE — это равновесие без пустых угроз. Второй не станет делать то, что ему же хуже.

A.8 · Chipping In Game

Ремонт крыши

Три соседа: Том, Джерри и пёс Спайк. Ремонт крыши стоит 4. Крыша нужна всем, но в разной мере: Тому на 3, Джерри на 2, Спайку на 1. Каждый называет число от 0 до 4. Если сумма хотя бы 4, крышу чинят, и каждый платит свою долю.

Главная мысль. Никто не хочет платить больше, чем ему стоит крыша. И никто не хочет переплачивать.

Инструкция

  1. Без ремонта. Проверь каждого: может ли он один «добить» сумму до 4 и не заплатить больше своей ценности? Если хоть кто-то может, это не равновесие.
  2. С ремонтом. Сумма должна быть ровно 4. Если больше, кто-то назовёт поменьше и заплатит меньше. Тогда каждый платит ровно своё число, и оно не больше его ценности.
  3. По очереди. Решай с конца. Спайк добавит 1, только если до 4 не хватает ровно 1. Джерри это знает. Том знает про обоих.

Пример из банка

Без ремонта: (0, 0, 0) и (1, 0, 0).

С ремонтом: сумма 4, Том не больше 3, Джерри не больше 2, Спайк не больше 1. Подходят (3, 1, 0), (2, 2, 0), (3, 0, 1), (2, 1, 1), (1, 2, 1).

По очереди: Том говорит 1, Джерри 2, Спайк 1. Крышу чинят.

Запомни: в равновесии с ремонтом сумма ровно 4, и каждый платит не больше своей ценности.

A.9 · Advertising Game

Реклама

Кафе и ночной клуб стоят рядом. Реклама одного помогает и другому. Каждый выбирает, сколько тратить на рекламу.

Главная мысль. Это A.6, только в конце ещё есть вариант «по очереди». Тот, кто ходит вторым, просто отвечает своим лучшим ответом.

Инструкция

  1. Найди два лучших ответа через производную, как в A.6.
  2. Одновременно: реши систему из двух лучших ответов.
  3. По очереди: вставь лучший ответ второго в прибыль первого. Найди максимум. Потом посчитай ответ второго.

Пример из банка

Лучшие ответы: кафе C = (8 + N) / 4, клуб N = 4 + C.

Одновременно: C = 4, N = 8, прибыль по 32.

Кафе первым: C = 6, N = 10. Клуб первым: N = 12, C = 5.

Запомни: первый игрок заранее подставляет ответ второго в свою прибыль.

A.10 · Collusion Game

Сговор

Двое играют одну и ту же игру каждый день, бесконечно. Они хотят договориться о хорошей для обоих клетке. Но соблазн обмануть есть.

Главная мысль. Договор держится, если обман сегодня даёт меньше, чем потом теряешь от наказания. Наказание: дальше навсегда играем «плохое» равновесие.

Инструкция

  1. Найди равновесие обычной игры. Вычёркивай строго худшие строки и столбцы, пока не останется одна клетка. Это и есть наказание.
  2. Для каждого игрока найди три числа: выигрыш по договору, выигрыш от лучшего обмана, выигрыш в наказании.
  3. Условие: договор ≥ (1 − δ) · обман + δ · наказание. Реши его относительно δ.
  4. Ответ — самое строгое условие из двух игроков. Если игроку обманывать незачем, для него условия нет.

Пример из банка

Наказание: клетка (B, R), по 6.

Договор (T, L) даёт по 11. Первому обман даёт 12: нужно δ ≥ 1/6. Второму обман даёт 15: нужно δ ≥ 4/9. Ответ: δ ≥ 4/9.

Договор (M, C): первому обманывать незачем, второму обман даёт 9. Ответ: δ ≥ 1/3.

Запомни: δ — насколько игрок ценит будущее. Чем он терпеливее, тем легче держать договор.
